# Datasets

The weeks published so far use no external dataset. All data in the Colab notebooks are simulated, with the assumptions stated next to the code, so that every result can be reproduced without a download. The interactive labs record the student's own experiments, for example the poll cycles measured on the Modbus bench in Week 8. They keep these data only in the browser until the student copies them into a Colab notebook. Public datasets used in later weeks will be listed here with their source, licence and verification status.
